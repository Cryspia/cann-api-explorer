# Track B · Runtime / AscendCL host API documentation

> **Positioning**: These are **host-side** APIs (executed on the CPU); they themselves **do not produce AI Core instructions and do not produce CAModel simulation reports**. Their role is "**scaffolding for launching kernels**" —— allocate memory, move data, start the stream, launch the kernel, synchronize, recycle. Every Track A example's `main.cpp` uses them. This document systematically records the host APIs actually used in this project (inventoried from the `main.cpp` of 85 units).

## Standard call sequence (the skeleton of every main.cpp)

```c
aclInit(nullptr);                                   // 1. initialize ACL
aclrtSetDevice(0);                                  // 2. bind device
aclrtStream stream = nullptr;
aclrtCreateStream(&stream);                         // 3. create stream

// 4. host/device memory allocation
float *xH; aclrtMallocHost((void**)&xH, bytes);     //    host side
uint8_t *xD; aclrtMalloc((void**)&xD, bytes, ACL_MEM_MALLOC_HUGE_FIRST);  // device side
aclrtMemcpy(xD, bytes, xH, bytes, ACL_MEMCPY_HOST_TO_DEVICE);  // 5. H2D copy in

ACLRT_LAUNCH_KERNEL(k_custom)(blockDim, stream, xD, zD);       // 6. launch kernel
aclrtSynchronizeStream(stream);                     // 7. wait for kernel to complete

aclrtMemcpy(zH, bytes, zD, bytes, ACL_MEMCPY_DEVICE_TO_HOST);  // 8. D2H copy back

aclrtFree(xD); aclrtFreeHost(xH);                   // 9. recycle
aclrtDestroyStream(stream); aclrtResetDevice(0); aclFinalize();
```

All calls are wrapped with the `CHECK_ACL(x)` macro (checks `aclError != ACL_SUCCESS` and returns an error).

## API groups

### Initialization / de-initialization
| API | Signature | Purpose |
|-----|------|------|
| `aclInit` | `aclError aclInit(const char *configPath)` | Initialize ACL, `nullptr`=default config. Process-level, called first. |
| `aclFinalize` | `aclError aclFinalize()` | De-initialize, called last. |

### Device
| API | Signature | Purpose |
|-----|------|------|
| `aclrtSetDevice` | `aclError aclrtSetDevice(int32_t deviceId)` | Bind the current thread to a device (simulation uses 0). |
| `aclrtResetDevice` | `aclError aclrtResetDevice(int32_t deviceId)` | Release device resources. |

### Stream (task queue)
| API | Signature | Purpose |
|-----|------|------|
| `aclrtCreateStream` | `aclError aclrtCreateStream(aclrtStream *stream)` | Create a stream; kernels are launched onto it. |
| `aclrtSynchronizeStream` | `aclError aclrtSynchronizeStream(aclrtStream stream)` | Block waiting for all tasks (including the kernel) on the stream to complete. Must be called before fetching results. |
| `aclrtDestroyStream` | `aclError aclrtDestroyStream(aclrtStream stream)` | Destroy the stream. |

### Memory
| API | Signature | Purpose |
|-----|------|------|
| `aclrtMallocHost` | `aclError aclrtMallocHost(void **ptr, size_t size)` | Allocate **host** memory (page-locked, efficient DMA). |
| `aclrtFreeHost` | `aclError aclrtFreeHost(void *ptr)` | Free host memory. |
| `aclrtMalloc` | `aclError aclrtMalloc(void **ptr, size_t size, aclrtMemMallocPolicy policy)` | Allocate **device (GM)** memory. policy commonly `ACL_MEM_MALLOC_HUGE_FIRST`. |
| `aclrtFree` | `aclError aclrtFree(void *ptr)` | Free device memory. |
| `aclrtMemcpy` | `aclError aclrtMemcpy(void *dst, size_t destMax, const void *src, size_t count, aclrtMemcpyKind kind)` | host↔device copy. kind: `ACL_MEMCPY_HOST_TO_DEVICE` / `ACL_MEMCPY_DEVICE_TO_HOST`. |

### Kernel launch
| API | Signature | Purpose |
|-----|------|------|
| `ACLRT_LAUNCH_KERNEL` | `ACLRT_LAUNCH_KERNEL(kernelName)(blockDim, stream, args...)` | The launch macro provided by AscendC (the stub header `aclrtlaunch_<kernelName>.h` is auto-generated by `ascendc_library`). `blockDim`=number of cores (multi-core sync examples use 8, others 1), `args`=GM pointers. **This is the only bridge between the host and the device kernel.** |

### Platform info (for host tiling)
| API | Signature | Purpose |
|-----|------|------|
| `platform_ascendc::PlatformAscendCManager::GetInstance()` | returns `PlatformAscendC*` | Fetches platform info (core count / UB size, etc.) when computing tiling on the host side. Used in this project by TopK (`TopKTilingFunc`) and Conv3D (`Conv3dTiling`). include `tiling/platform/platform_ascendc.h`. |

## Coverage boundary (best-effort)
- The 13 APIs above + 1 platform interface **already cover all host APIs used in the main.cpp of this project's 85 units**.
- Unused Runtime APIs (aclrtEvent events, aclrtMemset, multi-stream/context, aclrtMemcpyAsync, etc.) belong to the same family of extensions, added as needed; they are likewise host scaffolding and do not produce CAModel reports.
- The "verification" of Runtime APIs = calls return `ACL_SUCCESS` and run through together with the kernel (already implicit in the 82 PASSED units).
